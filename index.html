    SD カードなし（Bluetooth モード）

    SD カードが無いので、基板の Bluetooth モジュール（BM83）の音を再生しています（48kHz）。 曲の操作はスマホ側で行ってください。本体と Web アプリでは、音量・MAX VOL・ヘッドルーム・左右バランス・ 音質調整（DAC）・画面の設定ができます（SD カードが無いので保存はされません）。 SD カードを挿すと SD モードに戻ります。

      画面

      本体の画面が消灯中に変更しても、画面は点きません（本体のボタンで復帰します）。

      再生

      Bluetooth モードでは、ギャップレス再生・クロスフィード・低音・高音・ リプレイゲイン補正は効きません（Bluetooth の音は XIAO を通らず、直接 DAC へ入るため）。 変更した設定は保存されません。

      ヘッドホン・イヤホン向けに、左右の広がりを整えます（低い音ほど中央に寄ります）。 SD モードと USB-DAC モードのどちらでも効きます。桁溢れを避けるため、ON の間は全体の音量が 3〜5dB 下がります （USB-DAC モードでは、ON の間はビットパーフェクトではなくなります）。

      低音は約 230Hz 以下、高音は約 3.4kHz 以上を持ち上げ下げします（1kHz への影響は 1dB 未満）。 0 / 0 のときは音声データを一切通しません。持ち上げると桁溢れを避けるため全体が 1.8〜7.2dB 下がります。

      最近の曲はサンプルの間で 0dBFS を超えることがあり、DAC の中で歪みます。あらかじめ下げておくと避けられます （DAC の音量で下げるので、音声データは加工しません）。MAX VOL MODE のときも効きます。

      左右の音量差を 1dB 刻みで調整します（下げる側だけに効かせるので歪みは増えません）。

      アルバムごとの音量差をそろえます。SD カードを PC に挿し、 XIAO_DAP_ReplayGain.exe で測っておいてください（ラウドネスを ITU-R BS.1770-4 で測り、 カードに /XIAODAP/GAIN.BIN を書きます。アルバムを足したときは、足した分だけ測り直します）。 本体はその値を DAC の音量で下げるだけなので、音声データは加工しません。 大きいアルバムが下がるので、全体の音量は上げてお使いください。 OFF に戻すときは、下げていた分がそのまま戻って急に大きくなるため、本体が自動で一時停止し、 MAX VOL MODE を解除して音量を -30dB まで下げます。

      ライブラリの索引

      本体が自動で作り直すのは、カードを替えたとき・ルート直下のフォルダ（アーティスト）が増減したとき・ 今選んでいるアルバムの中身が変わったとき（停止中のみ）です。 それ以外のアルバムに曲を足したときやアルバムのフォルダを足したときは気づけないので、ここから作り直してください。 再生中の曲はいったん止まり、終わると同じ曲に戻ります。曲数によっては数十秒かかり、その間は本体も Web アプリも反応しません。 （必要な FW: v2.15.6 以降）

      FW の書き込み

      本体がブートローダで再起動し、PC に USB ドライブとして現れます。 そこへ .uf2 を放り込むか、PlatformIO の書き込み（pio run -t upload）を実行してください。 書き込みが終わると新しい FW で起動します。アプリは消えませんので、書き込まずに電源を入れ直せば元の FW に戻ります。 （この間 Web アプリとの接続は切れます。必要な FW: v2.11.0 以降）
