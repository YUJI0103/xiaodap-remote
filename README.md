# GARUDA Console for XIAO DAP

（旧称 XIAO DAP Remote）

XIAO DAP（Seeeduino XIAO SAMD21 を使った DAP 基板）を、PC のブラウザから USB 経由で操作する Web アプリです。

**https://yuji0103.github.io/xiaodap-remote/**

## できること

- 再生の操作（再生 / 一時停止・曲送り・アルバム送り・シーク）、音量、MAX VOL
- SD カードの曲のブラウズ（リスト表示 / アルバムアートのパネル表示）、曲の長さ
- シャッフル再生（全曲 / アーティスト / アルバム）
- アルバムアートの表示（フォルダの cover.jpg など、または曲に埋め込まれた画像）
- 画面・音質調整などの設定、機器情報、ログ
- SD モード ⇔ USB-DAC モードの切り替え（本体が再起動します）

## 必要なもの

- **XIAO DAP オリジナル FW v2.4.1 以降**を書き込んだ XIAO DAP 基板
- PC の **Chrome** または **Edge**（Web Serial API を使います。Safari・Firefox・iPhone では使えません）

## 使い方

1. XIAO DAP を PC に USB でつなぎます。
2. 上の URL を Chrome / Edge で開き、「接続」を押して XIAO DAP のポートを選びます。
3. 一度許可すると、次からは自動でつながります。SD モードと USB-DAC モードは USB の番号が違うため、それぞれのモードで最初に 1 回ずつ許可が要ります。

- ほかのアプリ（シリアルモニタなど）がポートを開いていると接続できません。
- 本体の画面が自動消灯しているときは、Web アプリで操作しても点きません（本体のボタンで復帰します）。
- 一度表示したアルバムアートはブラウザに保存されます（機器情報タブで消去できます）。

## このリポジトリについて

Web アプリ（`index.html` の 1 ファイル）だけを公開しています。ファームウェアのソースはここにはありません。
